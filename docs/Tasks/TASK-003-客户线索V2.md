# TASK-003-客户线索V2设计方案

## 文档信息

- 页面名称：客户线索
- 方案版本：V2
- 页面定位：AI推荐客户工作台
- 文档状态：待产品经理评审
- 设计范围：客户线索页面及其与AI智能接待、跟进中心、报价管理的衔接
- 本文不涉及代码、接口、数据库或页面开发

## 一、页面目标

客户线索页不再是普通的线索表，而是销售每天打开后即可做出判断的工作台。

老板或销售进入页面后，需要在第一屏马上知道：

1. 今天新增了哪些客户。
2. 哪些客户最值得优先联系。
3. AI为什么推荐这些客户。
4. 当前客户下一步应该进入接待、跟进还是报价。

### 核心定位

> AI每天帮销售判断“先联系谁”。

### 页面副标题

`AI持续识别客户行为，帮助销售优先处理最值得跟进的机会。`

### 设计结果

页面的主要动作不是浏览全部客户，而是从AI推荐开始，快速完成：

`AI推荐 → 查看理由 → 确认需求 → 进入接待 → 加入跟进 → 创建报价`

客户不能停留在线索页成为孤立数据。每条线索都必须能够自然进入下一步销售动作。

## 二、页面整体布局

延续现有深色企业软件风格，不使用传统CRM的大表格作为页面主体。推荐采用“顶部摘要 + 推荐区 + 列表与详情双栏”的结构。

```text
┌──────────────────────────────────────────────────────────────┐
│ 页面标题 / 当前企业 / 演示数据                               │
├──────────────┬──────────────┬──────────────┬────────────────┤
│ 今日新增线索 │ 高意向客户   │ 今日建议联系 │ 待销售处理     │
├─────────────────────────────────────────────────────────────┤
│ AI今日推荐：建议优先联系3家                       查看全部 → │
├──────────────────────────────┬──────────────────────────────┤
│ 左侧：客户线索列表             │ 右侧：客户详情                 │
│ 筛选 / 排序 / 线索行            │ 企业信息 / 需求 / 行为轨迹       │
│                                │ AI判断 / 销售建议 / 下一步动作   │
└──────────────────────────────┴──────────────────────────────┘
```

### 桌面尺寸建议

- 设计基准：1440 × 900
- 重点适配：1366 × 768
- 页面背景：深黑和深蓝
- 主内容区域：左侧列表约 44%，右侧详情约 56%
- 右侧详情固定在页面右侧，不使用全屏遮罩抽屉作为主要查看方式
- 详情内容过长时，在右侧面板内部滚动，页面主体不出现横向滚动

## 三、信息层级

### P0：第一眼必须看到

- 今日新增线索
- 高意向客户数量
- 今日建议联系数量
- 待销售处理数量
- `AI推荐今日先联系`入口
- 第一位AI推荐客户及推荐理由

### P1：用于判断先后顺序

- 客户企业名称
- 意向等级和优先级文字
- 最近行为
- 最近沟通时间
- AI推荐理由
- 当前状态

### P2：用于继续推进

- 客户企业资料
- 当前需求和采购阶段
- 行为时间轴
- 待确认问题
- 建议跟进话术
- 进入AI智能接待、加入今日跟进、创建报价

### P3：辅助信息

- 来源平台
- 所在地区
- 负责人
- 官网
- 企业规模
- 演示数据说明

页面不显示大量内容生产量、平台发布量、曝光趋势或无关运营指标。客户线索页只围绕“判断优先级和推动下一步”展开。

## 四、顶部核心摘要

### 1. 四项核心摘要

首屏顶部使用四个紧凑的摘要模块，不做成夸张的运营大屏。

#### 今日新增线索

- 数值示例：`8`
- 辅助文案：`较昨日新增 · 演示数据`
- 点击后：列表筛选为最近新增

#### 高意向客户

- 数值示例：`2`
- 辅助文案：`建议优先处理 · 演示数据`
- 点击后：列表筛选为高意向

#### 今日建议联系

- 数值示例：`3`
- 辅助文案：`AI已完成优先级判断 · 演示数据`
- 点击后：进入AI推荐视图

#### 待销售处理

- 数值示例：`6`
- 辅助文案：`等待接待、跟进或报价 · 演示数据`
- 点击后：列表筛选为待处理

四项摘要的数值仅用于演示，不显示成交金额、成交概率或收益预测。

### 2. 主入口

摘要区右侧或下方放置唯一高权重入口：

`AI推荐今日先联系`

点击后：

- 列表仅显示AI优先级最高的客户。
- 顶部进入`AI推荐中`状态。
- 右侧默认打开第一位推荐客户。
- 列表排序切换为AI推荐优先。

按钮下方可放低权重说明：

`基于演示客户的公开互动与咨询记录整理。`

## 五、AI今日推荐区域

### 1. 区域定位

这是页面首屏的核心成交区域，位于摘要区下方，优先级高于完整线索列表。

标题：

`AI今日推荐`

副标题：

`今天建议优先联系3家客户`

右侧操作：

`查看全部推荐`

### 2. 推荐卡片数量

默认展示3家客户，不超过3家，避免销售再次面对一长串待办。

每个推荐项采用横向紧凑结构：

- 左侧：优先级标记 `A / 高意向`
- 中间：企业名称、地区、需求产品
- 下一行：一条AI推荐理由
- 右侧：`查看详情`或箭头

推荐项示例：

#### A / 高意向

**金华某五金制品厂（演示客户）**

浙江金华 · 自动喷涂设备

AI推荐理由：`客户近期连续查看喷涂设备相关内容，并主动咨询产能，建议今天优先联系。`

#### B / 中高意向

**义乌某机械有限公司（演示客户）**

浙江义乌 · 自动化生产线

AI推荐理由：`客户收藏过自动化生产线内容，近期再次查看采购资料，建议确认产线长度和交付需求。`

#### B / 中高意向

**佛山某家具制造企业（演示客户）**

广东佛山 · 自动喷涂设备

AI推荐理由：`AI接待已收集基础需求，但工件尺寸和交付周期仍待确认，建议由销售补充沟通。`

### 3. 推荐理由规则

推荐理由必须来自当前演示数据中的明确字段或明确演示行为，不能自动生成没有依据的行为描述。

可使用的演示依据：

- 阅读了哪类内容
- 收藏或查看了哪类产品资料
- 主动发起了什么咨询
- AI接待是否已发生
- 哪些需求字段已确认或待确认
- 最近沟通时间和当前跟进状态

不使用以下口径：

- 客户成交概率82%
- 客户预计成交金额
- 客户已经确定采购
- 客户真实访问次数（没有可靠记录时）

## 六、左侧客户线索列表

### 1. 列表定位

左侧列表不是传统CRM数据表，而是按销售优先级排列的行动列表。

每条线索使用一行主信息加一行AI判断摘要，不堆叠所有字段。

### 2. 线索行内容

每条线索至少显示：

- 企业名称
- 演示客户标记
- 优先级：A / B / C / D
- 意向等级：高 / 中高 / 中 / 待确认
- 来源平台
- 所在地区
- 需求产品
- 最近行为
- 最近沟通时间
- 当前状态
- AI推荐理由摘要

### 3. 推荐的线索行结构

```text
┌─────────────────────────────────────────────────────────────┐
│ A  金华某五金制品厂（演示客户）              高意向          │
│    浙江金华 · 自动喷涂设备 · 知乎                          │
│    最近行为：查看文章并发起咨询              今天 10:24     │
│    AI建议：连续查看产品并主动咨询产能，建议今天优先联系。   │
│    状态：待报价                                               │
└─────────────────────────────────────────────────────────────┘
```

### 4. 优先级表达

不能只依靠颜色表达优先级，必须同时显示文字和等级：

- `A / 高意向`：当前最值得销售立即联系
- `B / 中高意向`：已有明显需求，建议当天处理
- `C / 培育`：存在兴趣，需要持续内容和低频跟进
- `D / 低优先`：信息不足或近期没有明确行为

颜色建议：

- A：低饱和绿色
- B：冰蓝
- C：低饱和橙色
- D：灰蓝

颜色只用于状态提示，不使用大面积彩色背景。

### 5. 当前选中状态

当前客户行必须有明显但克制的选中状态：

- 左侧一条科技蓝竖线
- 深蓝半透明背景
- 企业名称和优先级文字提高对比度
- 右侧详情同步更新

## 七、筛选与排序

### 1. 筛选项

保留以下实用筛选：

- 全部
- 高意向
- 待联系
- 已接待
- 已报价
- 培育中

筛选项使用单行分段控件，不使用大量下拉框。

### 2. 排序项

支持：

- AI推荐优先
- 最近互动
- 意向等级
- 最近新增

默认排序为：

`AI推荐优先`

排序名称始终可见，避免销售误以为列表按时间排序。

### 3. AI推荐筛选状态

点击`AI推荐今日先联系`后：

- 筛选栏显示`AI推荐中`状态。
- 列表只显示最高优先级客户。
- 空状态提示改为：`今天暂无新的AI优先推荐，请查看全部线索。`
- 允许点击`查看全部线索`恢复完整列表。

## 八、右侧客户详情

### 1. 详情定位

右侧不是普通的客户资料抽屉，而是销售做判断和执行下一步动作的工作区。

标题区显示：

- 企业名称
- 演示客户标记
- A/B/C/D优先级
- 意向等级
- 当前状态

右侧内容采用内部滚动，底部操作固定在详情面板下方。

### 2. 企业信息

显示字段：

- 企业名称
- 行业
- 地区
- 主营产品
- 企业规模
- 官网（如有）

没有数据时显示：

`待补充`

不使用空白、不编造官网和企业规模。

### 3. 客户需求

显示字段：

- 关注产品
- 当前需求
- 预算：未知时显示`待确认`
- 采购阶段或意向状态
- 已确认信息
- 待确认信息

示例：

- 关注产品：自动喷涂设备
- 当前需求：五金配件喷涂，日产量约3000件
- 预算：待确认
- 采购阶段：初步方案沟通
- 待确认：工件尺寸、喷涂材料、是否接入现有产线

### 4. 行为轨迹

使用紧凑时间轴，按时间从上到下排列：

```text
09:12  阅读自动喷涂设备采购指南
09:18  查看自动喷涂设备产品资料
09:25  主动咨询日产量与适用工厂
10:03  AI接待，完成基础需求收集
10:20  等待销售跟进
```

每个行为必须有来源或演示标识。没有具体时间的数据，显示相对状态，例如：

`最近一次互动：今天 · 演示数据`

不补造精确访问记录。

### 5. AI判断

AI判断区域显示四项：

- 意向等级：高 / 中高 / 中 / 待确认
- 推荐原因：一句销售可读的话
- 需要确认的关键问题
- 建议下一步动作

示例：

`客户近期连续查看喷涂设备相关内容，并主动咨询产能，建议今天优先联系。`

关键确认问题：

- 主要工件尺寸是多少？
- 每日产量是否稳定在约3000件？
- 当前使用的喷涂材料是什么？
- 是否需要接入现有生产线？

建议下一步：

`进入AI智能接待，补充需求后再创建报价。`

### 6. 销售建议话术

话术区域放在AI判断之后，使用较浅的深蓝背景突出可复制内容。

示例：

> 您好，看到您主要关注自动喷涂设备，想先确认一下您目前主要做什么工件，以及日产量大概是多少，我可以先帮您匹配一套适合的方案。

话术必须带入客户的具体需求，至少包含产品、行为或已知工况中的一项，不使用无客户上下文的通用营销话术。

## 九、右侧核心操作

右侧底部只保留三个核心动作。

### 主操作：进入AI智能接待

- 蓝色主按钮
- 进入接待页后保留当前客户上下文
- 用于继续收集客户需求和回答问题

### 次操作：加入今日跟进

- 描边按钮
- 点击后状态变为`已加入今日跟进`
- 右侧建议动作同步变为`等待销售执行`

### 次操作：创建报价

- 描边按钮
- 打开报价管理的客户上下文
- 报价默认处于人工确认状态

不在右侧同时放置“编辑客户、删除客户、发送邮件、导出报告”等低频操作。低频操作进入更多菜单或后续页面。

## 十、页面状态

### 1. 默认状态

- 默认排序：AI推荐优先
- 默认选中第一位A或B级客户
- 顶部摘要正常显示
- AI今日推荐展示3条
- 右侧显示第一位客户详情

### 2. AI推荐状态

- 顶部主入口显示为`AI推荐中`
- 列表只显示优先推荐客户
- 第一位客户默认选中
- 右侧突出推荐理由和建议话术

### 3. 空推荐状态

显示：

`今天暂时没有新的AI优先推荐`

辅助说明：

`可以查看全部线索，或等待新的客户互动。`

不显示虚构的推荐数量。

### 4. 无客户详情状态

当没有选中客户时，右侧显示：

`选择一条线索，查看AI判断和下一步建议。`

不显示空白大卡片。

### 5. 已加入跟进

- 线索行状态变为`今日跟进`
- 右侧操作按钮变为低权重的`已加入今日跟进`
- 不改变意向等级，不虚构客户反馈

### 6. 已报价

- 线索行状态显示`待人工确认报价`
- 右侧建议动作变为`确认报价信息`
- 可以进入报价管理，不直接显示正式成交结果

## 十一、与现有模块的衔接

页面底部或右侧详情中明确展示客户流转路径：

`客户线索 → AI智能接待 → 跟进中心 → 报价管理`

### 进入AI智能接待

- 带入当前客户名称、需求产品、意向等级和已确认信息。
- 接待页可以继续使用快捷提问、客户画像和转人工。

### 加入今日跟进

- 将当前客户状态更新为`今日跟进`。
- 跟进中心可以看到客户名称、推荐时间、跟进原因和建议话术。

### 创建报价

- 带入当前客户和关注产品。
- 报价状态默认为`待人工确认`。
- 不在客户线索页直接生成正式价格。

## 十二、演示数据边界

### 必须标注

- 页面顶部或核心推荐区显示`演示数据，不代表实际运营效果`。
- 客户名称旁显示`演示客户`。
- 行为时间轴、AI判断和推荐理由使用`演示数据`范围内的表达。

### 禁止出现

- 虚构真实成交金额
- 虚构真实企业访问记录
- 无依据的成交概率百分比
- 虚构官网、联系方式或企业规模
- 将AI推荐理由表述为已经确定采购
- 用行为记录承诺成交或询盘数量

### 可使用表达

- 高意向
- 中高意向
- 待确认
- 建议今天优先联系
- 建议确认工件尺寸
- 建议进入AI接待
- 建议人工跟进

## 十三、视觉规范

### 色彩

- 深黑：`#05070D`
- 深蓝：`#071A3A`
- 科技蓝：`#1267FF`
- 冰蓝：`#6FB7FF`
- 主文字：`#F2F6FF`
- 次文字：`#93A5C1`
- 高意向状态：低饱和绿色
- 待确认状态：低饱和橙色

### 组件原则

- 不使用白色大卡片。
- 不使用CRM Excel风格的满屏网格。
- 推荐区用少量横向面板，不堆叠十几张卡片。
- 客户列表行保留足够留白，AI推荐理由用一行简洁文字承载。
- 右侧详情使用分组和时间轴，不把所有字段塞成密集表格。
- 状态同时显示文字和颜色，不依赖颜色单独表达。
- 不使用Emoji，图标统一使用现有Lucide体系。

### 动效

- 默认页面进入时列表和详情轻微淡入。
- 点击AI推荐时，列表排序和详情切换使用短距离位移。
- 行选中只做背景和边框变化。
- AI推荐理由可以逐条出现，但不使用弹跳和粒子。
- 加入跟进、进入接待、创建报价使用明确的按钮状态反馈。

## 十四、验收标准

1. 首屏能够看懂今天新增了哪些客户，以及今天优先联系谁。
2. 顶部只展示新增线索、高意向、建议联系、待处理四项核心摘要。
3. 存在明确的`AI推荐今日先联系`入口。
4. 页面主体采用客户列表加详情双栏，不再以传统CRM大表格作为主视觉。
5. 每条客户线索都有可解释、可追溯的AI推荐理由。
6. 优先级同时显示A/B/C/D文字等级和意向等级，不只依靠颜色。
7. 右侧详情包含企业信息、客户需求、行为轨迹、AI判断和销售建议话术。
8. 销售建议话术必须结合客户产品、行为或已知需求。
9. 右侧只保留进入AI智能接待、加入今日跟进、创建报价三个核心动作。
10. 默认排序为AI推荐优先，筛选项保持实用且不过多。
11. 客户可以沿着“线索 → 接待 → 跟进 → 报价”继续推进，不停留在孤立列表。
12. 所有客户、行为、意向和AI判断都明确属于演示数据。
13. 页面不显示成交概率、成交金额或无依据的增长承诺。
14. 在1440×900和1366×768下，列表、详情和核心按钮均可读且不发生页面级横向溢出。

## 十五、方案结论

客户线索V2的核心不是让销售看到更多客户，而是帮助销售减少判断成本：

> 先看AI推荐，再看推荐理由，确认客户需求，立即进入下一步销售动作。

页面应成为从客户行为到销售行动的中间驾驶舱，而不是客户信息的终点。

本方案仅完成产品设计整理，不修改任何代码、页面、数据库或接口。待产品经理评审确认后，再进入原型和开发阶段。
